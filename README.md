# Raoul Berger — Portfolio

Personal portfolio website of **Raoul Berger**, Creative Director & Marketing Strategist based in Amsterdam.

🔗 **Live site:** https://raoulb24.github.io/

## About

A one-page portfolio showcasing creative direction, social media and marketing work for Amsterdam nightlife brands — including **Chin Chin Club**, **Mémoire** and **Fusion** — plus selected event branding and campaign design.

## What's inside

- `index.html` — the complete website (a single, self-contained file: all images and styling are embedded, so nothing else is required to run it)
- `design-bronbestanden/` — source design files (matchday posters, Dynasty rebranding, New Wave flyer)

## Highlights

- 37K+ followers managed across three brands
- 1.5M+ monthly views (Instagram & TikTok)
- Built and designed the chinchinclub.nl website
- All content created and directed in-house

## Built with

Plain HTML & CSS — no frameworks, no build step. Live TikTok feeds are embedded via TikTok's official embed.

## How to run locally

Just open `index.html` in any browser. Double-click the file — that's it.

## How to deploy

**GitHub Pages**
1. Push this repository to GitHub (Public).
2. Go to **Settings → Pages**.
3. Set *Source* to **Branch: main / (root)** and save.
4. Your site goes live at `https://<username>.github.io/<repo>/`.

**Netlify (alternative)**
Drag `index.html` onto [app.netlify.com/drop](https://app.netlify.com/drop) for an instant link.

> Note: the embedded TikTok feeds only load when the site is opened online (they need an internet connection).
